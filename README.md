# Стройинвест — лендинг на Nuxt

Nuxt 4, Vue 3 и TypeScript. Перенесены дизайн и содержимое согласованного лендинга: каменные, двухмодульные и трехмодульные дома, планировки, комплектации, оформление земли для ветеранов, этапы строительства и FAQ. Мобильная версия рассчитана на экраны от 320 px.

## Запуск

Нужен Node.js 22.12+; для проекта и CI используется Node.js 24.

```sh
npm ci
npm run dev
```

Для живых подсказок зарегистрируйтесь в [DaData](https://dadata.ru/profile/), подтвердите почту и укажите **API-ключ** в локальном `.env`:

```dotenv
NUXT_DADATA_API_KEY=ваш_API_ключ
```

Нужен именно API-ключ, а не Secret key. После изменения `.env` перезапустите Nuxt. Ключ используется только сервером, не включается в `runtimeConfig.public` и не передаётся в браузер. Без ключа форма работает с ручным вводом места.

По умолчанию локальный сервер запускается на http://localhost:2355.

Для просмотра с других устройств через https://strojinvest.cloudpub.ru в Cloudpub направьте эту публикацию на `http://localhost:2355`. Команда `npm run dev` использует `--public --host localhost`: Nuxt принимает внешний заголовок Host от туннеля, в том числе во время запуска и пересборки, а локальный сервер слушает localhost. После изменения команды запуска перезапустите Nuxt. Пока используете этот туннель, компьютер, Nuxt и Cloudpub должны работать.

## Проверки

```sh
npm run typecheck
npm test
npm run build
```

Браузерные тесты используют установленный Microsoft Edge на Windows. На Linux/CI предварительно выполните `npx playwright install --with-deps chromium`. Проверяются SSR-разметка, каталог, перенос планировки в заявку, подсказки DaData, ошибки API, содержимое запроса WhatsApp и размеры 320/375/622/1440 px. В UI-тестах ответы поиска подменяются фикстурами, ключ не нужен и квота DaData не расходуется. WhatsApp перехватывается, сообщения не отправляются.

Для проверки уже собранного сайта задайте `PLAYWRIGHT_BASE_URL` на адрес его HTTP-сервера перед `npm test`; в этом режиме тесты не запускают dev-сервер.

## Размещение с подсказками DaData

```sh
npm run build
node .output/server/index.mjs
```

Размещайте `.output` на хостинге с Node.js или используйте поддерживаемый Nuxt серверный/serverless preset. В окружении хостинга задайте `NUXT_DADATA_API_KEY`; production-сервер сам не читает локальный `.env`. База данных не нужна: сервер запрашивает подсказки, а заявка по-прежнему отправляется через WhatsApp пользователем.

Для размещения в подпапке задайте `NUXT_APP_BASE_URL=/имя-папки/` **перед сборкой**. Пути к изображениям, PDF, favicon и ресурсам Nuxt учитывают этот префикс. Для собственного домена без подпапки оставьте `/`.

`npm run generate` оставлен для варианта без серверного API. На чисто статическом хостинге подсказки DaData работать не будут; останется ручной ввод. Для полного функционала публикуйте серверную сборку.

## Настройки

Скопируйте `.env.example` в `.env`, если хотите изменить значения по умолчанию:

- `NUXT_PUBLIC_WHATSAPP_PHONE`: номер WhatsApp, сейчас `79889984896`.
- `NUXT_PUBLIC_SITE_URL`: абсолютный адрес сайта для canonical и Open Graph. До выбора домена можно оставить пустым.
- `NUXT_APP_BASE_URL`: `/` или путь подпапки хостинга.
- `NUXT_DADATA_API_KEY`: приватный API-ключ DaData для подсказок адресов.

В production задавайте секретный ключ через окружение хостинга. `.env` исключён из Git, `.env.example` содержит только пустое поле для ключа. Не добавляйте ключ в исходники или переменные `NUXT_PUBLIC_*`.

Поле запрашивает `/api/locations` спустя 300 мс после ввода от двух символов. Сервер обращается к DaData только по РФ и ограничивает выдачу уровнями от региона до населённого пункта. Подсказки показывают район и регион; в заявку попадает полное выбранное название. Устаревшие запросы отменяются, ошибка или отсутствие ключа не мешают ручному вводу и отправке заявки. Сервер ограничивает запросы до 60 в минуту на адрес прямого подключения в рамках процесса; при работе через прокси несколько посетителей могут делить этот лимит.

## Структура

```text
app/pages/index.vue                 композиция страницы и SEO
app/components/                     блоки лендинга, форма, планировки, поиск
app/composables/useLandingState.ts   выбранный дом и параметры заявки
app/composables/useAssetUrl.ts       пути с учетом baseURL
app/data/houses.ts                  планировки и размеры модульного дома
server/api/locations.post.ts        серверный запрос к DaData, ключ и лимит
server/utils/dadata.ts              параметры поиска и преобразование адресов
shared/types/location.ts            типы подсказок сервера и формы
app/utils/whatsapp.ts               составление сообщения
app/assets/css/main.css             общий дизайн и адаптация от 320 px
public/assets/                      изображения и PDF
```

Реактивное состояние и события реализованы средствами Vue. Старые `app.js`, `window.STROY_LOCATIONS` и ручная сборка DOM не используются. Содержимое отрисовывается при сборке/SSR; интерактивные элементы активируются после подключения Vue. SVG-стрелки вынесены в общий компонент `UiArrow`.

Карточки каменных планировок оформлены без миниатюр: рамка, площадь, описание и контрастное действие «Открыть планировку». В окне схемы прокручивается центральная часть, заголовок с SVG-крестиком и нижние действия остаются видимыми. Схему также можно открыть крупнее в отдельной вкладке. Отдельные тесты проверяют кнопки и окно на 320 × 568, 375 × 667, 568 × 320 и 1190 × 668 px.

## GitHub

Загружайте исходники вместе с `package-lock.json`. Не загружайте `node_modules`, `.nuxt`, `.output`, `dist`, `.env` и результаты тестов — они исключены через `.gitignore`.

В `.github/workflows/verify.yml` подготовлена проверка проекта на GitHub Actions: установка зависимостей, TypeScript, браузерные тесты и серверная сборка. Собранный сайт сохраняется как артефакт `stroyinvest-nuxt-site`. Автоматическое развертывание на внешний хостинг не настроено; его выбирают отдельно. Загрузка исходников на GitHub сама по себе не публикует работающий сайт.

## Источники материалов

Тексты, изображения и PDF перенесены из согласованного HTML-лендинга и материалов заказчика. Примеры домов не объявлены портфолио выполненных объектов. Спорная цена юридического сопровождения по-прежнему исключена.

Подсказки мест предоставляет [DaData](https://dadata.ru/api/suggest/address/). Локальный справочник HFLabs удалён. При поиске введённое название передаётся в DaData через сервер сайта; об этом есть подсказка рядом с полем. Остальные поля заявки в этот API не отправляются. Пользователь может ввести место вручную.

Документация: [развертывание Nuxt](https://nuxt.com/docs/4.x/getting-started/deployment), [runtime config](https://nuxt.com/docs/4.x/guide/going-further/runtime-config), [GitHub Actions](https://docs.github.com/en/actions).

## Состояние зависимостей

Проверка `npm audit` на 13.10.2026: критических предупреждений нет, осталось 11 предупреждений уровня high в транзитивных зависимостях Nuxt, связанных с `braces` и `node-forge`. Стандартный `npm audit fix` их не устраняет; принудительное исправление предлагает смену версии Nuxt и не применялось. В `package.json` закреплено исправление для `simple-git` через `overrides` (`^4.0.2`). Эти Node-пакеты не включаются в клиентскую статическую сборку `.output/public`, но предупреждения нужно учитывать и пересмотреть при обновлении инструментов или переходе к серверному размещению.

## Трехмодульный дом

В каталог добавлен «Барн на три модуля» по предоставленному КП: отдельная вкладка, визуализации, четыре ракурса, планировки дома и бани, технические параметры и ссылка на полный PDF (`public/assets/three-module-house.pdf`).

- 7 × 7,5 м + палуба из лиственницы: 3 137 500 ₽.
- 8 × 7,5 м + палуба из лиственницы: 3 375 000 ₽.
- Высота потолка: 2,1–2,45 м; стена / утепление: 226 / 150 мм; перегородка / утепление: 121 / 50 мм.

52,5 и 60 м² обозначены как расчет по внешним габаритам без палубы, а не полезная площадь. Актуальность цен и состав поставки согласуются при расчете. Планировка бани показана как альтернативный пример; самостоятельная цена бани в документе не выделена.

Размеры и цены находятся в `app/data/houses.ts`, блок — `app/components/ThreeModuleHouse.vue`. Выбор переносится в форму и WhatsApp; дробная площадь поддерживается. Добавлены браузерные проверки новых планировок, цен, PDF, клавиатурной навигации и запроса с площадью 52,5 м².
